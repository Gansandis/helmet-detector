วิธีทำงาน

ระบบตรวจเป็นสองขั้น เพื่อให้นับเฉพาะคนที่ขับขี่จริง ไม่นับคนเดินถนน

  1. หามอเตอร์ไซค์และคน

    โมเดลสำเร็จรูปมองหารถมอเตอร์ไซค์และคนในภาพ

  2. จับคู่ผู้ขับขี่

    คนที่ตัวซ้อนทับกับมอเตอร์ไซค์ ถือว่าเป็นผู้ขับขี่หรือผู้ซ้อน

  3. ตัดภาพแล้วตรวจหมวก

    ตัดเฉพาะภาพผู้ขับขี่แต่ละคน แล้วให้โมเดลหมวกที่เทรนเองตัดสินว่าสวมหรือไม่

ทุกขั้นทำงานในเบราว์เซอร์ของคุณ ภาพจากกล้องไม่ถูกอัปโหลดและไม่ถูกบันทึก

วิธีติดตั้ง

  1. ติดตั้ง Python

    เวอร์ชัน 3.9 ขึ้นไป จาก python.org

  2. แตกไฟล์และใส่โมเดล

    แตกไฟล์ zip แล้วนำ best.pt ไปวางในโฟลเดอร์เดียวกัน

  3. ติดตั้งไลบรารี

    เปิดเทอร์มินัลในโฟลเดอร์นั้น แล้วพิมพ์ pip install -r requirements.txt

  4. เริ่มใช้งาน

    พิมพ์ python helmet_detect.py --source 0 กด q เพื่อออก

ครั้งแรกโปรแกรมจะดาวน์โหลดโมเดลจับรถอัตโนมัติ ต้องต่ออินเทอร์เน็ต

คำถามที่พบบ่อย

ภาพจากกล้องถูกส่งไปเก็บที่เซิร์ฟเวอร์ไหม

ไม่ การตรวจจับทำงานในเบราว์เซอร์ของคุณทั้งหมด หน้าเว็บนี้ไม่ได้อัปโหลดหรือบันทึกภาพ

แม่นยำแค่ไหน

โมเดลหมวกได้ค่า mAP50 ประมาณ 0.84 บนภาพตรวจสอบ 1,955 ภาพ ซึ่งแปลว่าตรวจถูกเป็นส่วนใหญ่ แต่ยังพลาดได้

ที่มืด ฝนตก ระยะไกล หรือกล้องที่เห็นหัวไม่ชัด จะแม่นน้อยลง ควรใช้เป็นเครื่องช่วย ไม่ใช่ตัดสินแทนคน

เปิดกล้องไม่ได้ ต้องทำอย่างไร

เบราว์เซอร์จะอนุญาตกล้องเฉพาะเว็บที่เปิดผ่าน https ตรวจว่าลิงก์ขึ้นต้นด้วย https และกด "อนุญาต" เมื่อมีหน้าต่างขอใช้กล้อง

ถ้าเคยกดไม่อนุญาตไว้ ให้ไปที่การตั้งค่าเว็บไซต์ในเบราว์เซอร์ แล้วเปิดสิทธิ์กล้องอีกครั้ง

ทำไมภาพกระตุกหรือค้าง

ระบบรันโมเดลสองตัวต่อเฟรม เครื่องที่ช้าอาจได้เพียงไม่กี่เฟรมต่อวินาที ลองปิดแอปอื่น หรือใช้โปรแกรมเวอร์ชันรันในเครื่อง (แท็บดาวน์โหลด) ซึ่งเร็วกว่า

ทำไมต้องหามอเตอร์ไซค์ก่อน
